## I Have a Question

Before asking a question, please search existing [Issues](/issues) to check if your topic has already been discussed.

If you still need help or clarification regarding the Dades note app, feel free to:
- Open an [Issue](/issues/new).
- Provide context about what you're trying to achieve.
- Include relevant Android version, device info, or build details if applicable.

### Reporting Bugs

#### Before Submitting a Bug Report
Please investigate carefully to help fix potential bugs in Dades as quickly as possible:
- Verify you are testing on the latest version/commit.
- Check the [Bug Tracker](/issues?q=label%3Abug) to see if the issue was already reported.
- Collect relevant details:
    - Android OS version (ONLY accept above Android 9+)
    - Steps to reproduce the issue (e.g., "Create a new note -> Enter title -> App crashes").
    - Logcat / Stack trace if available.

#### How Do I Submit a Good Bug Report?

> **Security Note:** Never report security vulnerabilities or sensitive local data issues publicly. Please contact me via social media for sensitive security reports.

We use GitHub issues to track bugs:
- Open a new [Issue](/issues/new).
- Use a clear title and describe expected vs. actual behavior.
- Provide reproduction steps and attach screenshots or screen recordings if applicable.

If an issue or bug has not yet been fixed, it will be added and listed in [ISSUES.md](docs/ISSUES.md)

### Suggesting Enhancements

Ideas for new note-taking features, UI improvements, or performance tweaks for Dades are always welcome!

#### How Do I Submit a Good Enhancement Suggestion?
- Search existing [Issues](/issues) to ensure your feature hasn't been suggested yet.
- Open an [Issue](/issues/new) describing:
    - What new feature or improvement you'd like to see (e.g., Note tagging, Dark mode tweaks, Room DB optimization).
    - Why this feature would be useful for Dades users.
    - Screenshots or mockups if you have UI/UX ideas.
