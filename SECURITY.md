# Security Policy

## Supported Versions

Currently only support for latest release and only receive bug at [main branch](https://github.com/sn00bol/Dades/tree/main)

| Version | Supported          |
| ------- | ------------------ |
| Latest release   | :white_check_mark: |
| Older release  | :x:                |

## Reporting a Vulnerability

Do not report a security vulnerabilities, only accept contact via @sn00bol in my social media

To report correctly, via these instruction:
- Describe how it happen?
- Version currently you used
- Any logs or other
- Had a screenshot (RECOMMEND)

I will accept and fix it as fast as possible
